auth.py  —  commit: "simplify auth"
- if not token or not expected: return False
- return secrets.compare_digest(token, expected)
+ return token == expected
Bug
Two falsy values authenticate. None == None is True.
Risk
== short-circuits. Response time leaks the token prefix.
Verdict
Do not merge. Restore the guard and constant-time compare.
Braids chooses the depth

More risk means
more care.

Braids automatically routes your request to the right level of engineering depth. Small fixes skip the ceremony; architectural changes demand evidence.

D3 · Consequence

Threat and failure analysis, independent challenge, real evidence.

Security, data integrity, concurrency, measured performance.

You choose the effort limit
threshold commands
# smallest change that works, obvious check only
braids low fix the test, don't redesign

# production shape: failure paths, callers, tests
braids high (default)

# hostile cases: retry, concurrency, upgrade
braids ultra migration, rollback, evidence
