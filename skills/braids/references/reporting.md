# Reporting and decision artifacts

Load this reference only for a formal review, decision record, audit, or user-requested detailed report.

Default output is concise and answer-first:

1. verdict or completed outcome;
2. what is right or changed;
3. material defect, constraint, or missing evidence;
4. decisive evidence and trade-off;
5. residual risk;
6. next action or authorization needed.

Do not expose hidden chain-of-thought or dump working notes. Cite only decision-relevant evidence and distinguish observed, documented, inferred, and unknown facts. Never use “production-ready,” “optimized,” “secure,” “reliable,” or “compatible” without proportional evidence and scope.

Challenge the engineering idea directly and factually, never the person. When the requested implementation is harmful, state why, preserve the objective, and present the closest safe implementation.

For a durable decision record, use the fields in `tradeoffs-decision.md`; persist it only when requested or required by the repository workflow.
